# あなたのSNSアカウントが生まれ変わる（無料キット）

SNS コンサル・YouTube コンサル・運用代行が、お金をもらってやってきた流れを、**あなたの AI（Claude Code か Codex）で自分で回せる**ように、8つのステップにしました。

## 使い方（スマホだけで完了）
1. **「Use this template」→ Private（非公開）**で自分のリポを作る（あなたの事業情報を公開しないため。手順：`steps/00_setup.md`）
2. Claude Code（Code タブ）か Codex で、そのリポを選び「AGENTS.md を読んで、始めて」と送る
3. あとは AI が「次はこれ」と1つずつ案内します

### 今日の投稿をすぐ出したい時
「**投稿：◯◯**」と送るだけ。フック3案・本文・台本・画像の指示・サムネ文字・投稿日時・法務チェックを1枚で出し、「GitHub アプリで画像を保存 → 公式アプリで予約」の3手を案内します。

## 8つのステップ
| # | ステップ | コンサルが代わりにやっていたこと |
|---|---|---|
| 0 | 準備 | 初回ヒアリング |
| 1 | アカウントの棚卸し | 現状診断 |
| 2 | 誰に・何を・なぜあなたが | コンセプト設計 |
| 3 | のびた投稿の分析 | 分析レポート |
| 4 | 企画と1週間のカレンダー | 企画会議 |
| 5 | 作る（文章・カルーセル・動画） | 制作代行 |
| 6 | 投稿・予約 | 運用代行 |
| 7 | 週1回の振り返り → 3に戻る | 月次レポート |

## 使うほど良くなる仕組み
- 毎週の数字から「**勝ちパターン**」「**やめた事**」を `state/PROGRESS.md` に積み、次の企画は最初からそれを使う
- AI が賢くなるのではなく、**あなたのアカウントの手引きが育つ**（10本未満は仮説、2〜3か月で効く）

## 8 のあと：毎週の「改善の回」（SNS 1つ・週3本までなら 20〜30分）
- **数字の取り込み**：YouTube Studio／Instagram インサイト／X アナリティクスのスクショを貼るだけ（API をつなげば自動）
- **X は公開アルゴリズム（オープンソース）を週1で読み直し**、投稿づくりに反映
- **YouTube は Studio の「視聴者が見ているもの」「リサーチ」「Ask Studio」を材料に**、次の動画・タイトル・サムネを決める
- **サムネ・カルーセル画像は Codex か Gemini で**（文字はあとから重ねる）
- **予約投稿**：GitHub アプリで画像を保存 → 公式の予約機能（YouTube Studio／Meta Business Suite）。**確定はあなたが押す**。API の道具（`tools/`）は PC がある人だけ
- 詳しくは `weekly/WEEKLY.md`、SNS ごとの公式の条件は `platforms/`

## 会社で使う場合
- 企画と原稿は AI が出し、公開の確定は決裁者が押す。誰がいつ確定したかが `state/PROGRESS.md` に残る
- 鍵（API）は会社名義で発行し、`tools/README.md` の置き場所に（AI にも個人端末にも置かない）
- 企画の前に AI が「プロの目線チェック」（`weekly/WEEKLY.md`）を自分で通す

## 大事なこと
- パスワード・鍵・投稿の確定ボタンは、あなたが自分で押します。AI は勝手に公開しません。
- フォロワー数や売上は保証しません。到達点は「企画から投稿と振り返りまで、自分で回せる状態」です。
- Claude か ChatGPT の契約が要ります。SNS は公式の無料機能を使います。
- 実写風の AI 画像・音声を使う時は、各 SNS の「AI 生成」の申告をあなたが入れます。
- プロの型（フック・投稿時間・返信・炎上・ステマ/薬機/同意のチェック）は `steps/pro_kata.md`。最終判断は専門家へ。
