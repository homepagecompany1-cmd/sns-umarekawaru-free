# tools/ — 数字の取り込みと予約投稿の道具（任意）

全部**無くても**キットは回ります（本人が公式アプリで数字を見て、公式アプリで予約すればよい）。
API をつなぐと「数字の取り込み」と「予約投稿」が自動になります。慣れてから入れてください。

| ファイル | すること | 必要な物 |
|---|---|---|
| `yt_pull.py` | YouTube の動画一覧と数字（再生・視聴維持・CTR）を `data/youtube/` に保存 | Google Cloud の OAuth（本人が作る） |
| `yt_upload.py` | 動画をアップロードして公開予約（非公開でアップ → 公開日時を指定）＋サムネ設定 | 同上 |
| `ig_pull.py` | Instagram のインサイトを `data/instagram/` に保存 | Meta のアプリとアクセストークン（本人が作る） |
| `ig_publish.py` | 画像・カルーセル・リールを公開（または予約） | 同上 |
| `x_pull.py` | 自分の投稿と数字を `data/x/` に保存 | X の開発者アカウント（本人が作る） |
| `x_post.py` | 本文＋画像を投稿 | 同上 |
| `x_algo_pull.sh` | X の公開リポジトリから「重みづけ」に関する部分を取り出し `data/x_algo/` に保存（週1） | git だけ |

## 鍵の置き場所（共通の決まり）
- 鍵はこのリポに**置かない**。`.env` は `.gitignore` 済み。
- スマホだけの人：Claude の環境の **Network secrets**（Claude）／Codex の環境の **Secrets**（Codex）に本人が貼る。AI は値を見られない。
- PC の人：`.env` に本人が書く。AI は `.env` を読まない・表示しない。
- 鍵は**読み取りと投稿の最小権限**で作る。消す権限は付けない。

## 各道具の使い方
- 各ファイルの先頭に「本人がやること（画面の順）」と「AI がやること」を書いてある。AI は実行の前に、先頭を読んで本人に必要な操作を 1 つずつ案内する。
- 実行して `401`/`403` が出たら、鍵の置き直しを AI がやらず、本人に画面を案内する。
