# 6. 投稿・予約（運用代行の代わり）

## 標準の道（全員・スマホだけで完了）：公式アプリの予約投稿
1. AI が `out/` の素材ごとに「投稿日時・本文・画像/動画のファイル名」を一覧（コピペ用）にして **commit** する。
2. **画像をスマホに取り出す**：本人が GitHub アプリで `out/…/thumb_1.png` などを開く → 画像を長押し → 「保存」。（Codex は PR の Files から開く。merge 前でも見られる）
3. 本人が公式アプリの予約で入れる：
   - YouTube：YouTube Studio アプリ → アップロード → 題・説明・サムネ → 「公開予約」で日時 → 確定
   - Instagram/Facebook：Meta Business Suite アプリ → 投稿を作成 → 日時を指定 → 予約
   - X／Threads：公式アプリで投稿（予約が無ければ、通知を日時に入れて本人が押す）
   - 実写風の AI 素材を使った時は、アップロード画面の「AI 生成・合成」の申告に✔
4. AI は押す場所を1つずつ案内する。**確定ボタンは本人が押す。** 押したら `state/PROGRESS.md` の「確定記録」に1行。
5. 投稿後 **1時間**は返信の時間。AI は来たコメントへの返信案を3つ出す（`pro_kata.md` 6）。

## 慣れた人の道（**PC か常時動くクラウドがある人だけ**）：公式 API で予約・投稿
- スマホだけの人はこの道を使わない（API の認可画面・公開 URL・待ち受けが要る）。
- 使えるのは**各 SNS の公式 API だけ**（例：Instagram Graph API のコンテンツ公開、YouTube Data API のアップロード、X API、Threads API）。
- API には、本数・形式（カルーセルの枚数、音楽の扱いなど）・審査・料金の制限がある。**作業の前に必ず公式ドキュメントで最新の条件を確認**し、本人に「無料でできるか」「審査が要るか」を伝えてから進める。
- 鍵（アクセストークン）は本人が公式の画面で作り、本人が安全な場所（環境の Secrets など）に入れる。AI は値を見ない・書かない。
- 自動化してよいのは「本人が OK した投稿を、決めた時間に出す」ことだけ。自動フォロー・自動いいね・自動 DM はしない。
