# 0. 準備（初回ヒアリングの代わり）

AI は本人に、次の5つを**1つずつ**聞いて `state/PROGRESS.md` の「本人の基本情報」に書く。

1. どの SNS をのばしたいか（Instagram／YouTube／X／Threads／TikTok。最初は**1つ**に絞るよう勧める）
2. AI は Claude Code か Codex か
3. PC があるか（スマホだけでも進められる。PC があると画像・動画の作成が楽）
4. 1週間に何本なら無理なく出せるか（最初は週2〜3本を勧める。続く本数が正解）
5. 顔出しできるか・声だけか・画像だけか

## 終わりの合図
5つが埋まったら「0. 準備」を `完了` にする。
